# OpenBangla Keyboard — Linux Fork Wiki

This documentation is for the hasanmuammar/OpenBangla-Keyboard fork.

OpenBangla Keyboard is a Bangla/Bengali input method for Linux. This fork is Linux-only and focuses on portable, user-local installation for conventional and immutable Linux systems. KDE Plasma uses Fcitx5; other desktop environments use IBus.
