# OpenBangla Keyboard — Fork Wiki

This documentation is for the hasanmuammar/OpenBangla-Keyboard fork.

The fork is Linux-only and focuses on a portable, user-local installation model. KDE/Plasma uses Fcitx5; other desktop environments use IBus.
