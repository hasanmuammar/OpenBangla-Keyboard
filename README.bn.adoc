= ওপেনবাংলা কিবোর্ড — Linux-এর জন্য Bangla Keyboard | IBus ও Fcitx5

ওপেনবাংলা কিবোর্ড একটি open-source, Unicode-সমর্থিত **Bangla (Bengali) keyboard ও input method for Linux**, যেখানে ফোনেটিক ও ফিক্সড কিবোর্ড লেআউট, টাইপিং অটোমেশন, ডিকশনারি এবং অটোকরেক্ট সুবিধা রয়েছে।

এই repository-টি OpenBangla Keyboard-এর একটি পরীক্ষামূলক Linux-focused fork। এই fork-এর মূল কাজ হলো portable এবং user-local build ও installation workflow তৈরি করা, যাতে সাধারণ Linux-এর পাশাপাশি immutable বা image-based Linux-এও host system-এ system-wide package install না করেই এটি ব্যবহার করা যায়।

[IMPORTANT]
====
এটি upstream OpenBangla Keyboard-এর official release নয়।

Portable installer এবং integration-এর কিছু অংশ AI-generated বা AI-assisted। পরিবর্তনগুলো ধাপে ধাপে review ও test করা হচ্ছে, তবে এটিকে experimental software হিসেবে বিবেচনা করা উচিত।
====

== এই fork-এর বৈশিষ্ট্য

* Linux-only CMake build।
* KDE Plasma-তে Fcitx5 এবং অন্যান্য desktop environment-এ IBus নির্বাচন।
* বর্তমান user-এর জন্য `~/.local`-এ installation।
* Toolbox, Distrobox, Podman বা Docker-এর isolated build environment।
* XDG cache directory-তে persistent build ও staging cache।
* Qt এবং প্রয়োজনীয় runtime library user-local bundle হিসেবে রাখা।
* User-local IBus component registration।
* User-local uninstaller।

== ইনস্টলেশন

Submodule-সহ এই fork clone করুন:

[source,bash]
----
git clone --recursive https://github.com/hasanmuammar/OpenBangla-Keyboard.git
cd OpenBangla-Keyboard
----

তারপর installer চালান:

[source,bash]
----
bash tools/install.sh
----

Installer desktop environment শনাক্ত করে backend নির্বাচন করবে। KDE/Plasma-তে Fcitx5 এবং অন্য desktop environment-এ IBus নির্বাচন করা হবে।

এরপর installer Toolbox, Distrobox, Podman বা Docker-এর মধ্যে available একটি isolated build environment নির্বাচন করবে এবং সেখানেই build dependencies install করবে।

শুধু নির্বাচিত backend build করা হয়।

ডিফল্ট build parallelism 2 jobs। পরিবর্তন করতে:

[source,bash]
----
OPENBANGLA_BUILD_JOBS=4 bash tools/install.sh
----

Build ও staging data থাকে:

[source,text]
----
$XDG_CACHE_HOME/openbangla-keyboard/
----

অথবা `XDG_CACHE_HOME` নির্ধারিত না থাকলে:

[source,text]
----
~/.cache/openbangla-keyboard/
----

== আনইনস্টলেশন

বর্তমান user-এর OpenBangla installation সরাতে:

[source,bash]
----
bash tools/uninstall.sh
----

Build এবং staging cache-ও সরাতে:

[source,bash]
----
bash tools/uninstall.sh --purge-cache
----

== Manual Linux build

CMake build-এ একবারে একটি backend ব্যবহার করুন।

=== IBus

[source,bash]
----
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX="$HOME/.local" \
  -DENABLE_IBUS=ON \
  -DENABLE_FCITX=OFF

cmake --build build --parallel 2
cmake --install build
----

=== Fcitx5

[source,bash]
----
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX="$HOME/.local" \
  -DENABLE_IBUS=OFF \
  -DENABLE_FCITX=ON

cmake --build build --parallel 2
cmake --install build
----

প্রয়োজনীয় build dependencies-এর মধ্যে Qt5, CMake, Ninja, C/C++ compiler, Rust/Cargo, zstd development files এবং নির্বাচিত input-method backend-এর development files রয়েছে।

== Development

এই fork-এর development `develop` branch-এ হয়।

[source,bash]
----
git pull --recurse-submodules
bash tools/install.sh
----

Automated build cache পরিষ্কার করে rebuild করতে:

[source,bash]
----
rm -rf "$HOME/.cache/openbangla-keyboard/build"
----
