== Fork Notice: Experimental Development

This repository is an experimental fork of https://github.com/OpenBangla/OpenBangla-Keyboard[OpenBangla Keyboard], maintained independently from the upstream project.

The purpose of this fork is to experiment with a simpler, portable, user-local Linux build and installation workflow, with particular attention to immutable and image-based Linux systems. The goal is to avoid requiring system-wide installation or modifying the host operating system's package database.

The experimental work includes:

* Automatic input-method backend selection: KDE/Plasma uses Fcitx5; other desktop environments use IBus.
* User-local installation under the user's home directory.
* Build dependency isolation using a suitable Toolbox, Distrobox, Podman, or Docker environment where available.
* Persistent source and build caches to avoid unnecessary downloads and rebuilds.
* A simple installation workflow intended eventually to be usable by a graphical installer.

[IMPORTANT]
====
This fork is **experimental**. It is **not an official OpenBangla Keyboard release** and should not be treated as a production replacement for the upstream project.

Parts of the experimental installer and integration work are generated or assisted by AI. The code is reviewed and tested incrementally, but AI-assisted code may contain errors, incomplete assumptions, or regressions. Users should review changes before relying on them.
====

The upstream OpenBangla Keyboard code and its original licensing remain the basis of this project. Changes made in this fork are intended to be clearly separated from upstream functionality wherever practical.

*OpenBangla Keyboard* is an open source, Unicode compliant, Bangla input method for GNU/Linux systems.
It's a full-fledged Bangla input method with typing automation tools, includes many famous typing methods such as Avro Phonetic,
Probhat, Munir Optima, National (Jatiya) etc.

Most features of https://www.omicronlab.com/avro-keyboard.html[Avro Keyboard] are present in OpenBangla Keyboard.
So Avro Keyboard users will feel right at home in Linux with OpenBangla Keyboard.

== Features
* Features a __Top Bar__ like Avro Keyboard for easy configuration.
* Layout Viewer
* Phonetic Keyboard Layout (Avro Phonetic)
  ** 100% compatibility with current Avro Phonetic scheme.
  ** Dictionary support can predict and suggest phonetically similar words with correct spelling on the fly.
  ** Autocorrect feature for numerous commonly mistyped words.
  ** Autocorrect support brings commonly used English words to Bangla (like, Facebook, download etc.) even with their original English spelling.
  ** User can add and edit autocorrect entries.
  ** Support for preview window to see originally typed text right under the cursor.
* Fixed Keyboard Layout
  ** OpenBangla Keyboard comes with Probhat, Munir Optima, Avro Easy, Bornona, National (Jatiya) keyboard layouts out of the box.
  ** OpenBangla Keyboard supports Avro Keyboard Layout files (version 5).
* Typing Automation tools for Fixed Keyboard layout
  ** Automatic vowel forming.
  ** Old style "Reph".
  ** Traditional "-Kar" joining.
  ** Automatic "Chandrabindu" position fixing.


== Installation

The experimental installer builds OpenBangla from the current source tree and installs it for the current user.

[source,bash]
----
git clone --recursive https://github.com/hasanmuammar/OpenBangla-Keyboard.git
cd OpenBangla-Keyboard
bash tools/install.sh
----

The installer:

* selects IBus for most desktops and Fcitx5 for KDE/Plasma;
* selects an available build environment: Toolbox, Distrobox, Podman, or Docker;
* installs build dependencies inside that environment;
* builds OpenBangla with CMake;
* installs the result under `~/.local`.

Only the selected input-method backend is built.

Build files and staging data are kept in:

[source,text]
----
$XDG_CACHE_HOME/openbangla-keyboard/
----

or `~/.cache/openbangla-keyboard/` when `XDG_CACHE_HOME` is not set.

The default build parallelism is 2 jobs. To change it:

[source,bash]
----
OPENBANGLA_BUILD_JOBS=4 bash tools/install.sh
----

== Custom Build

The installer is a wrapper around the normal CMake build system. You can build OpenBangla manually when you need more control over the configuration or build process.

=== IBus

[source,bash]
----
cmake -S . -B build -G Ninja   -DCMAKE_BUILD_TYPE=Release   -DCMAKE_INSTALL_PREFIX="$HOME/.local"   -DENABLE_IBUS=ON   -DENABLE_FCITX=OFF   -DENABLE_BOTH=OFF

cmake --build build --parallel 2
cmake --install build
----

=== Fcitx5

[source,bash]
----
cmake -S . -B build -G Ninja   -DCMAKE_BUILD_TYPE=Release   -DCMAKE_INSTALL_PREFIX="$HOME/.local"   -DENABLE_IBUS=OFF   -DENABLE_FCITX=ON   -DENABLE_BOTH=OFF

cmake --build build --parallel 2
cmake --install build
----

Do not enable both backends for the user-local build.

The required development packages include:

* C/C++ compiler
* CMake
* Ninja
* pkg-config
* Rust and Cargo
* zstd development files
* Qt5 development files
* IBus development files for an IBus build
* Fcitx5 development files for an Fcitx5 build

== Development

After updating the source tree:

[source,bash]
----
git pull --recurse-submodules
bash tools/install.sh
----

To start a clean CMake configuration, remove the build directory:

[source,bash]
----
rm -rf build
----

For the automated installer, remove its cached build directory instead:

[source,bash]
----
rm -rf "$HOME/.cache/openbangla-keyboard/build"
----

The installer is experimental and may change during development.
