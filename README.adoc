= OpenBangla Keyboard — Bangla Keyboard for Linux | IBus & Fcitx5

image:https://img.shields.io/badge/platform-Linux-333333?logo=linux&logoColor=white[Linux] image:https://img.shields.io/badge/input%20method-IBus%20%7C%20Fcitx5-0F6CBD[Input methods] image:https://img.shields.io/badge/build-CMake-064F8C?logo=cmake&logoColor=white[CMake] image:https://img.shields.io/badge/UI-Qt5-41CD52?logo=qt&logoColor=white[Qt5] image:https://img.shields.io/badge/C%2B%2B%20%7C%20Rust-00599C?logo=rust&logoColor=white[C++ and Rust]

OpenBangla Keyboard is an open-source, Unicode-compliant **Bangla (Bengali) keyboard and input method for Linux**. It provides phonetic and fixed keyboard layouts, typing automation, dictionary support and autocorrection.

This repository is an **experimental Linux fork of OpenBangla Keyboard** with a portable, user-local build and installation workflow for conventional Linux desktops and immutable or image-based Linux systems.

[IMPORTANT]
====
This is an experimental fork, not an official upstream OpenBangla Keyboard release.

The portable installer and related integration work contain AI-generated or AI-assisted code. The code is reviewed and tested incrementally, but regressions are possible.
====

== What this fork provides

* **Linux-only CMake build** with one input-method backend per build.
* **Automatic backend selection:** KDE Plasma uses Fcitx5; other desktop environments use IBus.
* **User-local installation** under `~/.local` without a system-wide package install.
* **Isolated builds** using Toolbx, Distrobox, Podman, or Docker.
* **Persistent build and staging cache** under the XDG cache directory.
* **Bundled Qt5 and required runtime libraries** for the user-local installation.
* **Automatic IBus component registration** for user-local installations.
* **User-local uninstaller** with optional cache removal.

== Bangla keyboard and input-method features

The OpenBangla Keyboard codebase is built for Bangla typing on Linux and includes:

* Phonetic Bangla typing, including Avro-style phonetic input.
* Fixed Bangla keyboard layouts.
* Unicode-compliant Bengali text input.
* Typing automation for fixed layouts.
* Dictionary-based suggestions and autocorrection.
* A Qt-based configuration interface.
* Linux desktop integration through IBus or Fcitx5.

== Installation

Clone this fork with its submodules:

[source,bash]
----
git clone --recursive https://github.com/hasanmuammar/OpenBangla-Keyboard.git
cd OpenBangla-Keyboard
----

Run the installer:

[source,bash]
----
bash tools/install.sh
----

The installer automatically detects the desktop environment, selects the input-method backend, chooses an available isolated build environment, installs the build dependencies inside that environment, and builds only the selected backend.

Supported build environments are https://github.com/containers/toolbox[Toolbx (`toolbox`)], https://github.com/89luca89/distrobox[Distrobox], https://github.com/containers/podman[Podman], and https://github.com/moby/moby[Docker]. No manual builder selection is required.

When a new Podman build environment is needed, the installer explains the temporary disk usage and asks for confirmation. The temporary Debian 13 slim build container can be removed automatically after a successful installation, freeing the space used by its build dependencies.

The default build parallelism is 2 jobs. To change it:

[source,bash]
----
OPENBANGLA_BUILD_JOBS=4 bash tools/install.sh
----

Build and staging data are stored in:

[source,text]
----
$XDG_CACHE_HOME/openbangla-keyboard/
----

or:

[source,text]
----
~/.cache/openbangla-keyboard/
----

when `XDG_CACHE_HOME` is not set.

== Uninstallation

Remove the current-user installation:

[source,bash]
----
bash tools/uninstall.sh
----

To remove the build and staging cache as well:

[source,bash]
----
bash tools/uninstall.sh --purge-cache
----

== Manual Linux build

The CMake project supports one input-method backend per build.

=== IBus

[source,bash]
----
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX="$HOME/.local" \
  -DENABLE_IBUS=ON \
  -DENABLE_FCITX=OFF

cmake --build build --parallel 2
cmake --install build
----

=== Fcitx5

[source,bash]
----
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_INSTALL_PREFIX="$HOME/.local" \
  -DENABLE_IBUS=OFF \
  -DENABLE_FCITX=ON

cmake --build build --parallel 2
cmake --install build
----

The build requires Qt5, CMake, Ninja, a C/C++ compiler, Rust/Cargo, zstd development files, and the development files for the selected input-method backend.

== Development

The fork is developed on the `develop` branch.

After updating the repository:

[source,bash]
----
git pull --recurse-submodules
bash tools/install.sh
----

For a clean automated rebuild:

[source,bash]
----
rm -rf "$XDG_CACHE_HOME/openbangla-keyboard/build"
----

If `XDG_CACHE_HOME` is not set:

[source,bash]
----
rm -rf "$HOME/.cache/openbangla-keyboard/build"
----

Fork-specific documentation is kept under `docs/wiki/`.
